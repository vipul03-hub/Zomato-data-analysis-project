# 🍽️ Zomato Data Analysis Project

## 📌 Project Overview
With the rapid growth of food delivery platforms like Zomato, understanding customer ordering behavior and restaurant performance is essential for business success. This project analyzes restaurant data to uncover patterns in customer preferences, ratings, and spending habits.

## 🎯 Objective
The goal of this analysis is to help Zomato make data-driven decisions by identifying:
- Popular restaurant types among customers
- Customer engagement through votes and ratings
- Spending behavior of key customer segments (e.g., couples)
- Performance differences between online and offline orders

## 🧠 Approach
- Data Cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Visualization of customer behavior and trends
- Insight extraction for business recommendations

## 📊 Key Questions
1. Which type of restaurant is most preferred by customers?
2. How many votes does each restaurant type receive?
3. What ratings do most restaurants have?
4. What is the average spending of couples per order?
5. Which ordering mode (online/offline) receives higher ratings?
6. Which restaurant types receive more offline orders?

## 💡 Business Value
These insights can help Zomato:
- Optimize restaurant recommendations
- Improve customer targeting strategies
- Enhance user experience in online ordering
- Support restaurants in boosting offline engagement
